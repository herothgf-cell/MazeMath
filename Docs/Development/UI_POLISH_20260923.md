# 모모의 작은 모험 — UI 수정 / 2026-09-23

대상: Unity 2022.3.62f2, main, Adventure.unity. 기존 저장 형식과 월드의 진행/제작/퍼즐 규칙은 변경하지 않는다.

## 수정 범위

- 탐험 HUD와 카메라를 분리한다. 헤더/하단 조작부는 별도 공간을 사용하며 Camera.rect는 그 사이만 렌더링한다. Safe Area와 해상도 변경에 맞춰 동시에 갱신한다.
- PC에서는 터치 조작 버튼을 기본으로 숨긴다. 터치 기기에서는 표시하며 일시정지 메뉴에서도 켜고 끌 수 있다.
- 목표는 상단의 작은 카드, 장비 6칸은 하단 도크에 배치한다. 알림은 목표 영역을 잠시 사용하므로 플레이어 위에 나타나지 않는다.
- 숫자 정답은 약 0.6초 피드백 후 자동 닫는다. 게임이 멈춰도 unscaled time으로 진행한다. 오답은 열린 상태를 유지한다.
- 성공 후 연타/키보드 재입력 차단, 다른 창으로 이동 시 이전 닫기 예약 취소, 닫을 때 선택/터치 상태 해제.
- 일반 버튼 16, 본문 14~18, 제목 22, 수식 최대 28의 캔버스 기준 글자 크기를 사용한다. 폭이 부족하면 줄바꿈/축소하며 임의 확대하지 않는다.
- 검은 테두리와 짙은 녹색 베벨 대신 밝은 크림·민트·하늘·살구색, 둥근 카드와 얕은 그림자 사용.
- 8~12픽셀 스프라이트를 96픽셀 이상의 안티앨리어싱된 로봇/도구 일러스트로 교체한다. 필터는 Bilinear. 외부 이미지/폰트 파일을 포함하지 않는다.
- 캐릭터 위 설명은 가까운 대상 하나만 표시한다. 순서 발판 숫자는 유지하며 메쉬 최대 크기를 제한한다. 동굴은 밝은 장난감 블록 톤으로 변경한다.

## 실행

로컬 변경을 보관한 뒤 `git pull --ff-only origin main`.
`MazeMath > Play Adventure` 또는 `Assets/MazeMath/Scenes/Adventure.unity`에서 Play.
Setup Project/씬 재생성/저장 초기화는 필요 없다. 기존 이어하기 사용 가능.

## 검증

- Tools/CoreTests/AdventureUiRegressionTests.cs: 자동 닫기 시간, 오답 유지, 연타 방지, 이전 창 예약 취소, 7개 화면 크기의 카메라/HUD 영역 분리.
- Assets/MazeMath/Tests/PlayMode/UI/AdventureHudPolishTests.cs: 실제 AdventureGame으로 정답 후 닫힘/연타/새 창 유지/화면 버튼 위치/글자 크기/스프라이트 필터 검사.
- 순수 C# CI 결과와 Unity PlayMode/화면 검증을 구별한다. 작성 환경에는 Unity Editor가 없어 Unity 테스트와 실제 WebGL/APK 화면 검증은 실행하지 못한다.

## 직접 확인할 항목

1. 캐릭터 이동/점프/사다리가 상하 UI 뒤에 숨지 않는지.
2. 정답 후 0.6초 내 창이 닫히고 이동이 재개되는지. 오답에는 닫히지 않는지.
3. 정답 직후 Esc → 가방 열기를 해도 가방이 자동으로 닫히지 않는지.
4. PC/터치/가로·세로 전환에서 HUD, 키패드, 제작, 지도 버튼 겹침이 없는지.
5. 한글 폰트가 배포 환경에 지정된 경우 글리프 누락이 없는지. 폰트 미지정 환경은 기존 영문 fallback 유지.
