# 모모의 공방 모험 — 모바일 웹 15.2

플레이: https://herothgf-cell.github.io/MazeMath/

설치 없이 실행되는 HTML/Canvas 모바일 웹판이다. Unity 본편과는 별도 실행/저장이다. 15.1의 그래픽, 15개 챕터, 채굴, 3×3 제작, 도구 연출, 이동·회전 발판, 도르래, 기계 정지와 친근한 몬스터를 유지한다.

## 15.2 퀴즈 업데이트

- 골렘 문제를 한 번 받으면 정답 후 약 1초 뒤 다음 문제로 이어진다. 마지막 문제에서 챕터를 완료한다.
- `쉬기 · 저장`으로 언제든 중단할 수 있다. 완료한 문제를 다시 강요하거나 미완료 문제를 새 답으로 바꾸지 않는다.
- 카드 위치 바꾸기: 현재 줄의 위치를 기준으로 옮긴다. 직접 조작, 처음 줄 비교, 한 단계 보기 지원.
- 같은 모양의 값 찾기: 같은 기호는 같은 수. 연결된 두세 개 단서로 작은 정수를 추론한다.
- 각 챕터의 2층에 `모모의 생각 장치` 하나가 추가된다.
- 골렘 문제 수: 1~3장 5개, 4~6장 6개, 7~9장 7개, 10~12장 8개, 13~15장 9개.
- 새 문제는 최근 128개 출제 기록과 비교해 반복을 줄인다. 기존에 풀던 문제는 그대로 복원한다. 유한한 퍼즐 배치나 학습용 고정 순서는 재등장할 수 있다.
- 덧셈 범위와 추론 단계가 완만히 증가한다. 곱셈은 2·3·5단, 나눗셈은 나누어떨어지는 값, 답은 100 미만. 제한 시간·오답 재료/XP 벌점은 없다.

## 소스와 배포

`index.html`은 이전 15.1의 완전한 기준 소스다. 인접한 예전 분리형 JS는 10.1 회귀 검사용으로만 남아 있다. 새 기능은 `quiz/`의 모듈로 관리한다.

`node Web/Instant/quiz/build.cjs`가 기준 소스의 정확한 함수 경계와 삽입 위치를 검증해 `_site/index.html`을 만든다. 소스 구조가 달라지면 무조건 진행하지 않고 실패한다. GitHub Pages는 **검사를 통과한 `_site`만** 배포한다. `index.html`을 직접 열면 기준 버전이며, 15.2를 로컬에서 확인하려면 생성된 `_site`를 HTTP로 제공한다.

검사:

```sh
node Web/Instant/quiz/build.cjs
node --test Web/Instant/quiz/*.test.cjs
node Web/Instant/quiz/browser.cjs
```

Node 검사는 생성된 런타임의 카드/기호 정답, 유일해, 난이도, 반복 억제, 저장 호환, 15장 경로와 기계 진행을 확인한다. 브라우저 검사는 실제 HTTP로 생성 페이지를 로딩하고 Chromium/WebKit에서 15장 각각의 골렘 연속 문제, 필드 사고력 문제, 오답, 쉬기/타이머 취소, 저장/새로고침, 모바일 화면을 확인한다. 골렘 구간은 준비된 유효한 저장 fixture로 진입하며, 전체 필드 도보 완주와 동일한 검사는 아니다.

`MM_INLINE=1`은 로컬 네트워크가 막힌 환경의 명시적 스텁 모드다. CI에는 설정하지 않는다. 실제 iPhone/Android 장시간 성능 및 아이의 이해도는 자동 검사와 별도다.

기존 `mazemath.instant.v1` 저장 키와 완료한 챕터/장비/XP를 유지한다. 이미 완료한 챕터는 추가 문제 때문에 다시 깨야 하지 않는다.
