# MazeMath Instant — 모바일 즉시 플레이판

사용자가 지금 휴대폰에서 실행할 수 있도록 작성한 별도의 JavaScript/Canvas 웹판입니다. Unity WebGL 빌드 산출물이 아니며 Unity 프로젝트, Assets, 에디터 버전, 기존 빌드 설정은 변경하지 않습니다.

## 실행

HTTPS 정적 호스트에서 index.html, core.js, game.js를 같은 폴더로 제공합니다. 공개 Git 커밋의 Web/Instant/index.html을 rawcdn.githack.com의 commit-pinned 주소로 서비스할 수도 있습니다. 해당 서비스는 HTML에 첫 접속 확인 화면을 표시할 수 있습니다. 개발용 CDN에는 가동 보장이 없습니다. 운영용 배포는 별도 전용 도메인을 권장합니다.

## 플레이

새 탐험 시작 → 숫자 장치 → 작업대 복귀 → 곡괭이 팔 제작 → 균열벽 → 무게 다리 → 사다리 → 거울/발판 → 수호 골렘. 직접 걷기, 점프, 사다리, 숫자 주관식, 상자 운반, 거울 회전, 순서 발판, 기본 제작, 센서 3×3 조합, 장착과 인챈트 선택, 지도, 골렘 보호막 3단계를 포함합니다.

모바일 터치 조작을 기본 제공하며 세로/가로에서 UI와 게임 화면을 분리합니다. 한글은 시스템 글꼴을 사용합니다. 별도 폰트, 이미지, 오디오, 프레임워크 다운로드가 없는 경량 시험판입니다. 원본 게임을 그대로 변환한 것은 아니며 일부 연출과 장비 보조 효과는 단순화했습니다. 온라인 멀티플레이나 계정 시스템은 없습니다.

## 저장

키 `mazemath.instant.v1`으로 브라우저 localStorage에 저장합니다. Unity/Android 앱 저장과 공유되지 않습니다. 동일 브라우저/동일 출처에서만 이어하기를 기대할 수 있습니다. 개인정보/계정정보를 수집하지 않습니다. 사이트 데이터 삭제 또는 브라우저 저장 제한으로 기록이 사라질 수 있습니다. 미완료 환경 퍼즐은 재접속 시 초기화되고 해결한 장치는 유지됩니다.

## 검증

- `node --test Web/Instant/core.test.cjs`: 생성/제작/보상 중복/이동/사다리/보스/저장 데이터 검사.
- `node Web/Instant/browser.test.cjs`: Playwright Chromium + WebKit에서 로컬 HTTP 서버를 통해 실제 JS 실행, 터치 이벤트, 오답 유지, 정답 자동 닫기, 제작, reload/이어하기, 퍼즐 및 보스 흐름을 검사합니다.
- 실제 iPhone 하드웨어 검증과는 구분합니다.
- 작성 컨테이너에서는 네트워크 없는 DOM에 소스를 주입하여 Chromium 모바일 393×852, 844×390, 320×568, 667×375 화면을 확인했습니다. 이 오프라인 검사의 storage는 테스트 더블이므로 실제 영속 저장 검증과 다릅니다.

코어 레이아웃/재료 비용/주요 진행은 `Assets/MazeMath/Scripts/Adventure/Domain`을 참고했습니다. 웹판 변경은 Web/Instant 아래에 한정하고 Unity 본편과 독립적으로 관리합니다.
