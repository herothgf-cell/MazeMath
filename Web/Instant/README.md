# 모모의 블록 탐험 — 모바일 웹 10.1

플레이: https://herothgf-cell.github.io/MazeMath/

설치 없이 실행되는 HTML/Canvas 모바일 웹판이다. Unity 2022.3.62f2 본편의 WebGL 산출물이 아니며 Unity 소스와는 별도 실행/저장이다.

## 플레이

`이어하기`는 기존 기록을 유지한다. `챕터 선택`에서 완료한 장이나 열린 장을 선택할 수 있다. 기존 5장 완료자는 6장부터 이어갈 수 있다. 화면에 `10장 업데이트` 또는 `블록 모험 10.1`이 보이면 새 버전이다.

좌우 이동, 위아래 사다리, 점프, 조사 버튼을 사용한다. 아래 핫바에서 도구를 고르면 손에 해당 도구가 보인다. 곡괭이로 캐기, 렌치로 수리, 부스터 점프, 실드 보호, 센서 스캔을 직접 사용한다. 발전기는 세 번 수리하면 돌아가기 시작한다.

작업대의 모든 장비는 3×3 조합식이다. 조합법 보기와 첫 곡괭이의 반투명 가이드를 제공한다. 조합이 틀리거나 재료가 부족하면 재료를 소모하지 않는다.

골렘은 직접 문제를 낸다. 필드 목표를 해결하고 골렘에게 말을 걸어 `골렘의 문제 받기`를 누른다. 마지막 정답 뒤 자동으로 다음 장이 열린다. 오답·힌트·다시 보기에 XP나 재료 페널티는 없다.

## 6~10장

6. 초록 물레방아 숲: 수로, 발전기, 저울, 숫자 규칙.
7. 얼음 기계 동굴: 채굴, 부스터, 3→6→9 발판, 거울.
8. 사막 태양 발전소: 발전기, 센서 조건, 실드, 반사판.
9. 구름 시계 공방: 시계 발전기, 두 상자 퍼즐, 기억·단계 계산.
10. 별빛 세계수 성채: 도구 종합과 골렘의 마지막 5문제.

## 구현 경계

`chapter-data.js`: 위치/테마/필드/보스 문제.
`puzzles.js`: 시드 문제, 실제 포트 연결과 광선 반사, 소코반 규칙.
`core.js`: 이동·제작·목표·보스·저장 v3.
`world-renderer.js`: 발전기·도구·골렘·발판 Canvas 연출.
`game.js`: 터치·대화·문제·제작·저장 UI.

v1/v2 저장은 자동 변환하며 이전 원본을 별도 키에 백업한다. 신규 6~10장은 3층 공통 골격의 1차 콘텐츠 확장이다. 자유 건축이나 무한 채굴 월드는 포함하지 않는다.

## 검사와 배포

```bash
node --test Web/Instant/core.test.cjs
npm install --no-save --ignore-scripts playwright@1.63.0
npx playwright install --with-deps chromium webkit
node Web/Instant/browser.test.cjs
```

테스트 모드(`?test=1`)는 실제 입력/물리 루프를 일정한 프레임 단위로 진행한다. 일반 공개 플레이에는 이 옵션을 붙이지 않는다. Pages는 Node·Chromium·WebKit 검사가 모두 통과한 뒤 배포한다. 실제 휴대폰 장시간 성능 검증은 별도로 필요하다.
