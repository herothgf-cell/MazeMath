# 모모의 공방 모험 — 모바일 웹 15.1

플레이: https://herothgf-cell.github.io/MazeMath/

GitHub Pages에서 설치 없이 실행되는 HTML/Canvas 모바일 웹판이다. Unity 본편과는 별도 실행/저장이다.

## 15.1 배포 형식

`index.html`은 검증된 15.1 런타임을 한 파일로 묶은 배포본이다. 기존 모듈 소스는 이전 10.1 회귀 검사용으로 저장소에 남아 있으며, Pages에서 실제로 실행되는 게임은 `index.html`에 내장된 15.1 코드다. `standalone.test.cjs`가 배포되는 이 파일 자체를 Chromium/WebKit에서 검사한다.

## 게임 내용

- 챕터 1~15
- 3×3 조합 제작, 채굴, 핫바 도구 사용
- 발전기/렌치/곡괭이/부스터/실드/센서 직접 연출
- 이동·회전·길이 조절 발판
- 추와 도르래, 기계 정지/재개
- 챕터 11부터 친근한 몬스터/숫자 만남
- 골렘이 직접 문제를 내고 마지막 문제 뒤 다음 챕터 해금
- 기존 `mazemath.instant.v1` 브라우저 저장 키 유지 및 이전 저장 마이그레이션
- 움직임 줄이기/가벼운 효과 옵션

문제 난이도는 챕터 10 이후에도 매우 조금씩만 증가한다. 곱셈은 쉬운 2·3·5단 중심, 나눗셈은 나누어떨어지는 문제를 유지하며 오답에 재료/XP 페널티를 주지 않는다.

## 배포 검사

Pages 배포 전 다음을 검사한다.

1. 기존 모듈 규칙 회귀 테스트
2. 실제 15.1 `index.html` 로딩
3. 15개 챕터와 10장 기계/11장 몬스터 데이터
4. Chromium + WebKit 터치 이동
5. 실제 localStorage 저장 후 새로고침/이어하기
6. 393×852, 844×390, 320×568, 667×375 모바일 레이아웃
7. 브라우저 page error 없음

실제 iPhone/Android 장시간 성능·배터리 검증은 자동 브라우저 검사와 별도다.
